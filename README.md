<h1 align="center">GeoInk</h1>

<p align="center">
  <strong>A cross-platform GEOINT application for collecting, and visualizing geospatial data.</strong>
</p>

<p align="center">
  Supports <strong>Windows</strong>, <strong>Linux</strong>, and <strong>Android</strong>.
</p>

## Features

* 🗺️ **Map visualization** — Create and visualize markers, circles, polygons, and polylines.
* 🌐 **GeoJSON support** — Import and work with data in the GeoJSON format.
* 🔎 **Text parsing** — Extract geographic coordinates directly from text.
* ↩️ **Undo & redo** — Easily revert and restore changes with built-in history support.




> Note: GeoInk is still under development and lacks many advanced features, but it provides the basic functionality needed to get you started.
